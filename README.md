# Resilience: Operation Midway Blitz, One Year Later

Static landing page for The Daily Northwestern's resilience special issue.

## Page structure

- `index.html` contains the hero, embedded Flourish timeline and story categories.
- `styles.css` provides the responsive layout and the purple, yellow and orange palette.
- `script.js` is reserved for lightweight page behavior as the project develops.
- `assets/resilience-cover.jpg` is the supplied issue artwork, optimized for the web.

The Flourish timeline is embedded. The story reel video and article photos are not in the repository yet; add the MP4 and connect it to the background video element in `index.html` when the media is ready. The spreadsheet currently has links for six Evanston stories and two NU stories; the El Diario category is ready for its links.
